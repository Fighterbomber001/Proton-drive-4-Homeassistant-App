# Proton Drive Backup

Die App überträgt fertige Home-Assistant-Backups zu Proton Drive. Zusammen mit der [separaten Integration](https://github.com/Fighterbomber001/Proton-drive-4-Homeassistant) erscheint **Proton Drive** als zusätzlicher Sicherungsort im Home-Assistant-Backup-Menü. Die App zeigt die letzten bestätigten Sicherungen mit Name, Datum und Größe.

Für Home Assistant OS auf amd64 (x86-64) mit Home Assistant Core ab 2026.11.2. Einrichtung und Hinweise findest du im Reiter **Dokumentation**.
