# Sicherheitsmeldungen

Melde Fehler mit möglicher Sicherheitsrelevanz möglichst privat über
**Security → Report a vulnerability**, sofern der Kanal im Repository
aktiviert ist. Ist kein privater Meldeweg verfügbar, bitte zuerst
in einem Issue einen privaten Kontakt erfragen – ohne Details oder Dateien.

Für normale Probleme genügen die Versionen von Home Assistant, Integration
und App, die Fehlerkategorie und kurze Schritte ohne private Daten.
Niemals Passwörter, Anmeldelinks, Kopplungsschlüssel, Backup-Schlüssel,
Sicherungsdateien oder unbereinigte Logs veröffentlichen.
